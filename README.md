A comprehensive financial dashboard and stock market analysis tool built in Python and deployed via Streamlit.

## 💡 Overview
- **Goal:** Provide real-time financial insights and predictive stock analysis.
- **Features:** Advanced financial charting, interactive widgets, and ML-based trend prediction.

## 🛠️ Tech Stack
- **Dashboard:** Streamlit, Plotly
- **Data:** Pandas, NumPy
- **ML:** Scikit-Learn
